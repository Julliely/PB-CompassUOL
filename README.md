# PB CompassUOL

Este repositório contém todos os documentos e artefatos das sprints do **Programa de Bolsas Compass UOL**.

Aqui estão centralizados arquivos de **planejamento de testes**, **mapas mentais**, **collections do Postman**, entre outros.

---

## Estrutura do Repositório

- Todas as atividades de cada **sprint** estão organizadas em **branches separadas**.
- Dentro de cada branch, todos os arquivos relacionados à sprint estão na pasta **`Documentos`**.

---

## Como Navegar

1. Selecione a **branch** correspondente à sprint que deseja consultar.
2. Acesse a pasta **`Documentos`** para encontrar os arquivos da sprint.
3. Todos os documentos de planejamento, testes e mapas mentais estarão disponíveis nessa pasta.

---

## Observações

- Cada branch representa uma sprint específica, garantindo que os arquivos de diferentes sprints não se misturem.
- Utilize este repositório como referência centralizada para todas as atividades do programa.
